プライバシーポリシー — 路線価めくり

最終更新日：2026年11月12日

「路線価めくり」（以下「本アプリ」）は、年分と住所から、国税庁が公開している路線価図を探して開くためのアプリです（iPhone・Android・Windows）。本アプリは、必要のないものを集めないことを設計の方針にしています。

1. アカウントとサーバーについて

  • アカウント登録はありません。 メールアドレス・電話番号・氏名は、一切お預かりしません。
  • 運営は、本アプリのためのサーバーを持っていません。 あなたが探した住所や開いた図が、運営に送られることはありません。

2. 探すときの通信について

住所や地図の点から路線価図を探すとき、本アプリは次の公的機関のサービスと直接通信します。

通信先送るもの使い道
国土地理院（住所検索）入力した住所の文字住所を緯度・経度に直す
国土地理院（地理院タイル）地図に表示している範囲地図を表示する
国税庁（財産評価基準書のサイト）開く路線価図の番号・年分路線価図（PDF）と索引を読み込む

それぞれの通信には、各機関の利用規約・プライバシーポリシーが適用されます。

3. 端末の中にだけ保存されるもの

次のものはあなたの端末の中にだけ保存され、外部には送られません。

端末の中だけ内容
最近探した住所探した住所・地図で選んだ地点（見つかったものだけ）
保存した路線価図国税庁から読み込んだ PDF（国税庁のものをそのまま保存します）
無料版の件数その月に探した件数を数えるための記録（月が変わると数え直します）
Pro かどうか「Pro を利用中かどうか」のはい／いいえの1つだけ
  • 最近探した住所は、アプリ内の「履歴を消す」でいつでも消せます。
  • 本アプリを削除すると、これらはすべて消えます。復元はできません。

4. 路線価図の上の文字の読み取りについて

Pro では、路線価図に印刷された街区番号を読み取り、住所の街区を赤い輪で囲んで塗ります。

  • 読み取りは端末の中だけで行います。 使うのは端末の機能で、iPhone は Apple の Vision、Android は Google の ML Kit（端末の中で動く版）、Windows は Windows の文字認識です。本アプリが図の画像や読み取った文字を外部に送ることはありません。
  • Android：文字認識の部品（Google の ML Kit）は、診断と利用状況の分析のため、端末の情報（メーカー・機種・OS の版）・アプリの版・インストールごとの識別子・処理にかかった時間・画像の形式や大きさなどを Google に送ります（Google の説明：developers.google.com/ml-kit/android-data-disclosure）。この一覧に、図の画像や読み取った文字そのものは含まれていません。

5. 位置情報・カメラ・連絡先について

  • 本アプリは、位置情報・カメラ・写真・連絡先の許可を求めません。
  • 地図の点は、あなたが地図を押して選んだ場所だけを使います。現在地を取得することはありません。
  • 住所の入力でキーボードのマイク（音声入力）を使った場合、その処理は端末（OS）の機能によるもので、本アプリは音声を受け取りません。

6. 広告について（iPhone・Android の無料版）

  • 無料版では、その月の2件目から5件目を探すとき、あなたが「広告を見て表示する」を押したときだけ、動画の広告（Google AdMob のリワード広告）を流します。押さなければ広告は流れません。
  • 路線価図を表示している画面には、広告を表示しません。
  • 表示するのは非パーソナライズ広告です。あなたの過去の行動にもとづいて選ばれることはありません。
  • iPhone：本アプリはトラッキング許可（ATT）のダイアログを出しません。したがって広告識別子（IDFA）にアクセスしません。広告配信の仕組み上、表示回数の制限や集計のために識別子が使われることがありますが、広告のターゲティングには使われません。
  • Android：広告の配信のため、Google の広告 SDK が広告 ID・IP アドレス（おおよその地域の推定に使われることがあります）・広告の表示やタップの情報・動作の診断情報を Google に送ります（Google の説明：developers.google.com/admob/android/privacy/play-data-disclosure）。広告 ID は Android の設定からリセット・削除できます。
  • 探した住所・開いた図・保存した図が、広告のために提供されることはありません。
  • Pro をご利用中は、広告は流れません。Windows 版には広告はありません。
  • アクセス解析（アナリティクス）は入れていません。 利用状況を追跡する仕組みは組み込んでいません。

7. 有料機能（路線価めくり Pro）について

  • Pro は月額の自動更新の購読です。購入・更新・解約・復元は、iPhone では Apple の App Store、Android では Google Play、Windows では Microsoft Store を通して行われます。
  • 運営はクレジットカード番号などの決済情報を受け取りません。
  • 購入のためのサーバーを運営は持っていません。 購読しているかどうかは Apple・Google・Microsoft が保持し、本アプリはそれを読むだけです。
  • そのため、購読の記録はあなたの Apple ID（Android では Google アカウント、Windows では Microsoft アカウント）に結び付きます。同じアカウントなら、別の端末でも「購入を復元」で引き継げます（iPhone・Android・Windows の間では引き継げません）。

必要に応じて本ポリシーを変更することがあります。重要な変更があった場合は、このページの最終更新日を改めます。
